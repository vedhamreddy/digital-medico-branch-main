DIGITAL MEDICO - WEBSITE PROJECT

If you downloaded this project from GitHub:
1. Extract the entire ZIP.
2. Install Node.js 22+ and Python 3.12+.
   On Windows, select "Add Python to PATH" during Python installation.
3. Open the extracted folder in VS Code.
4. Open a Command Prompt terminal inside VS Code and run:
   npm ci
   npm run dev
5. Keep the terminal open and visit http://localhost:5173.
