DIGITAL MEDICO - LOCAL DEMO

1. Extract the entire ZIP (do not run files directly inside the ZIP).
2. Install Python 3.12 or newer if it is not already installed.
   https://www.python.org/downloads/
   On Windows, select "Add Python to PATH" during installation.
3. Double-click RUN_WINDOWS.cmd inside the extracted folder.
4. Keep its terminal window open. The browser opens http://localhost:5173.
   If it does not open automatically, type that address into your browser.

No Node.js installation is needed to run this prebuilt package.
